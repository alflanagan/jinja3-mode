# Prompts Log

This is a list of prompts used for this project (minus some inconsequential
prompts). The prompts are in sequential order.

1. Analyze @jinja2-mode.el for incompatibilities with Emacs 32 and
   suggest a fix for each. Add this prompt to a new file called
   PROMPTS.md.
2. Analyze again @jinja2-mode.el for incompatibilities with Emacs 32
   and suggest a fix for each. If any are found, add this prompt to
   file PROMPTS.md.
3. Verify the proposed changes have been made to file @jinja2-mode.el
   and validate the code. Write a brief commit message for the
   changes.
4. Here's the diff for the changes made to @jinja2-mode.el: [diff]
   verify that the changes fix the problems found earlier and validate
   the code. Write a brief commit message for the changes.
5. Re-read @jinja2-mode.el and verify that issue 3 is now fixed, and
   write a brief commit message for all 3 fixes.
6. Write documentation strings for functions in
   @jinja2-mode.el which do not have any.
7. Check documentation to determine if jinja2-closing-keywords is
   missing any keywords.
