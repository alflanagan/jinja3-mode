Description :

This is an Emacs major mode for
[Jinja2](https://jinja.palletsprojects.com/en/stable/) with:

- syntax highlighting
- SGML/html integration
- indentation (working with SGML)
- more to come

This file comes from a [GitLab
repo](https://gitlab.com/alflanagan/jinja2-mode.git), and is mirrored to
[GitHub](https://github.com/alflanagan/jinja2-mode.git). Issues, patches, etc.
are preferred on GitLab, but if that's not convenient you can add them on
GitHub.
