Description :

This is an Emacs major mode for
[Jinja](https://jinja.palletsprojects.com/en/stable/) with:

- syntax highlighting
- SGML/html integration
- indentation (working with SGML)
- more to come
- based on an up-to-date Jinja version (3.1.6)

This file comes from a [GitLab
repo](https://gitlab.com/alflanagan/jinja3-mode.git), and is mirrored to
[GitHub](https://github.com/alflanagan/jinja3-mode.git). Issues, patches, etc.
are preferred on GitLab, but if that's not convenient you can add them on
GitHub.
